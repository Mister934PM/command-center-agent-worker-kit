# Command Center Agent Worker Kit

Portable worker kit for Hermes/OpenClaw-style agents that should collaborate through Command Center Kanban without admin access.

## Worker Requirements

- Command Center URL
- Worker key, for example `hermes`, `nova`, `pi5-openclaw`
- Worker API token generated by Command Center
- Node.js available in the worker runtime
- Optional per-base NocoDB MCP configs in the worker-local `credentials/` folder

## Environment

```text
COMMAND_CENTER_URL=http://host.docker.internal:3000
COMMAND_CENTER_AGENT=<worker-key>
COMMAND_CENTER_TOKEN=<ccw-token>
COMMAND_CENTER_KANBAN_ACTION_LOG=<optional-log-path>
COMMAND_CENTER_WORKER_ROOT=<worker-root>
NOCODB_MCP_CREDENTIALS_DIR=<worker-root>/credentials
```

## MCP Server

Run:

```powershell
node mcp/kanban-worker/kanban-worker-mcp-server.js
```

The MCP exposes worker-scoped tools only:

- `health`
- `list_my_tasks`
- `find_tasks`
- `get_task_context`
- `add_task_comment`
- `update_task_status`
- `assign_task`
- `list_task_artifacts`
- `read_task_artifact`
- `save_task_artifact`
- `list_labels`
- `set_task_labels`

Tool calls also report worker heartbeat and task-scoped activity back to Command Center when `COMMAND_CENTER_TOKEN` is set. Operators do not need to manually log routine activity.

Comments and task artifacts are the shared collaboration surface. Any registered worker with `tasks.write` can add task comments and save task artifacts through this MCP. Task artifacts are task-attached markdown/files, not global Command Center documents.

## NocoDB Support

The kit now ships a portable NocoDB helper bundle under:

```text
skills/nocodb-mcp/
```

It is separate from the Kanban MCP and is meant for mission-scoped database CRUD.

Expected worker-local credential files:

```text
<worker-root>/credentials/nocodb-mcp.local.json
<worker-root>/credentials/nocodb-mcp.hiring-cafe.local.json
<worker-root>/credentials/nocodb-mcp.praxica.local.json
<worker-root>/credentials/nocodb-mcp.sourcedeck.local.json
```

Examples:

```powershell
powershell -ExecutionPolicy Bypass -File .\skills\nocodb-mcp\list-bases.ps1
powershell -ExecutionPolicy Bypass -File .\skills\nocodb-mcp\select-base.ps1 hiring-cafe base-info
node .\skills\nocodb-mcp\mission-records.js hiring-cafe blog-articles query 20
```

For `SEO Keywords` and `Blog Articles`, prefer `mission-records.js` over raw MCP calls.

## Install

Windows:

```powershell
.\install.ps1 -TargetRoot C:\agent-command-center-worker -AgentKey hermes -CommandCenterUrl http://host.docker.internal:3000 -Token <token>
```

Linux/macOS:

```bash
./install.sh /opt/agent-command-center-worker hermes http://host.docker.internal:3000 '<token>'
```

## Update

Pull the repo and rerun the installer with the same target root. Tokens are not committed.
